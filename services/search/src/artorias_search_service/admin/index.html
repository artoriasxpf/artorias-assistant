在测试集合验证写入

示例使用 tasks_sandbox。启动服务前，将它追加到 ARTORIAS_SEARCH_COLLECTIONS。依次发送「初始化快照」「新增文档」「更新文档」，再用搜索模板验证。重复操作前，可从状态响应读取 last_seq，下一条增量事件使用 last_seq + 1。

在线 Assistant 管理 tasks 集合的消费游标。该集合适合用页面查询和查看状态。手工写入只改 Search Service 的索引，可能与 Assistant 的 outbox 冲突。
